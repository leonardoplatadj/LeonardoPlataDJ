# Leonardo Plata — sitio oficial

Sitio estático (HTML + CSS + JS, sin dependencias). Listo para GitHub Pages.

## Estructura
```
index.html            página principal (ES / EN)
assets/css/style.css  estilos (Montserrat, negro + rojo)
assets/js/main.js     idioma, menú móvil, animaciones
assets/img/           fotos y logos
```

## Publicar en GitHub Pages
1. Crea un repositorio nuevo (por ejemplo `leonardoplata.github.io` o `sitio`).
2. Sube todos estos archivos a la raíz del repositorio.
3. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`.
4. En uno o dos minutos el sitio queda en `https://<tu-usuario>.github.io/<repo>/`.
5. Para usar un dominio propio, agrégalo en **Settings → Pages → Custom domain**.

## Editar
- Textos: `index.html`. Cada texto existe en español (`lang="es"`) e inglés (`lang="en"`).
- Fotos: reemplaza el archivo en `assets/img/` con el mismo nombre.
- Colores: variables al inicio de `assets/css/style.css`.
